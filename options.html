Tab Closer

Enter one JavaScript regex per filter. Matches are case-sensitive by default. Inline modifiers supported by your browser can change that. Filters match the full URL supplied by the browser, including query and fragment. For example: ^https://www\.reddit\.com/

URL filters

Blank filters are ignored. Spaces in nonblank filters are part of the regex. Paste a URL into a filter, then select Add escape characters to match that text literally. Saving filters never scans open tabs.

Test a URL

The tester uses the current draft. It does not visit the URL or close a tab.
